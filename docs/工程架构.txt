## 🗂️ 工程目录结构

```
MyAwesomeFPSGame/
├── CMakeLists.txt                 # 顶层 CMake 构建文件
├── cmake/                         # CMake 模块和工具链文件
│   └── ...
├── external/                      # 第三方依赖（如 SDL, Bullet, etc.）
│   └── ...
├── engine/                        # 引擎核心模块（如 ECS、渲染、物理等）
│   ├── CMakeLists.txt
│   ├── core/                      # 引擎核心，日志、配置、时间、平台等
│   ├── ecs/                       # 实体组件系统
│   ├── renderer/                 # 渲染系统（OpenGL/Vulkan/DirectX）
│   ├── physics/                  # 物理系统（集成 Bullet 或自研）
│   ├── input/                    # 输入系统（键盘/鼠标/手柄）
│   └── audio/                    # 音频系统
├── game/                          # 游戏逻辑代码（模块化组织）
│   ├── CMakeLists.txt
│   ├── actors/                   # 角色、敌人、NPC
│   ├── gameplay/                 # 规则系统、得分、胜利条件
│   ├── levels/                   # 关卡逻辑（可以包含加载关卡配置的代码）
│   ├── weapons/                  # 武器系统（如射击逻辑、弹药）
│   ├── UI/                       # UI 系统逻辑
│   └── player/                   # 玩家控制逻辑（移动、输入绑定）
├── assets/                        # 所有静态资源文件
│   ├── models/                   # 模型
│   ├── textures/                 # 贴图
│   ├── sounds/                   # 音效
│   ├── levels/                   # 关卡数据（可以是 JSON、XML、或自定义格式）
│   ├── shaders/                  # GLSL/HLSL 着色器
│   └── fonts/                    # 字体资源
├── tools/                         # 开发工具（关卡编辑器、资源打包器等）
│   └── level_editor/            # 示例：关卡编辑器项目
├── scripts/                       # 构建脚本（如 Python 脚本用于资源处理）
├── tests/                         # 单元测试和集成测试
├── docs/                          # 项目文档、设计文档等
└── main.cpp                       # 游戏入口（或 src/main.cpp）
```

---

## 📌 各部分说明

### `engine/`

* 抽象出游戏引擎的核心模块。
* 模块化程度高，可以复用于多个项目。
* 一般由多个静态库/动态库组成。

### `game/`

* 只包含该游戏项目独有的逻辑。
* 各类角色（Player, Enemy）、武器、规则、UI 等应在此实现。
* 建议使用插件式或模块化设计，比如一个 `.so`/`.dll` 对应一个子系统。

### `assets/`

* 非源码资源，如模型、贴图、音效。
* 可以建立元数据系统，用于热更新或资源打包。

### `levels/`

* 如果你实现了关卡系统，每个关卡可以是一个 JSON 文件、Lua 脚本、甚至是你自定义的二进制格式。

## 🧩 CMake 示例（顶层）

```cmake
cmake_minimum_required(VERSION 3.20)
project(MyAwesomeFPSGame)

set(CMAKE_CXX_STANDARD 20)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# 启用模块目录
list(APPEND CMAKE_MODULE_PATH "${CMAKE_SOURCE_DIR}/cmake")

# 包含外部库
add_subdirectory(external)

# 添加引擎模块
add_subdirectory(engine)

# 添加游戏逻辑
add_subdirectory(game)

# 添加主程序
add_executable(MyAwesomeFPSGame main.cpp)
target_link_libraries(MyAwesomeFPSGame PRIVATE engine game)
```

## 🔧 其他建议

### 分包构建

使用 `add_subdirectory(engine/renderer)` 方式将引擎子模块拆分编译，提升构建效率和代码隔离。

### 命名空间设计

在 C++ 代码中，建议使用如下命名空间结构：

```cpp
namespace Engine::Renderer { ... }
namespace Game::Player { ... }
```

### 资源管理

创建统一的 `ResourceManager` 类，用于按需加载模型、贴图、音效、关卡等。

## ✅ Unreal Engine（UE5）标准项目结构（简化版）

举个常见的 UE 项目结构：

```
MyUnrealProject/
├── Config/               # 项目配置（INI）
├── Content/              # 所有资源（模型、音效、材质等）
│   ├── Characters/
│   ├── Weapons/
│   ├── Levels/
│   ├── UI/
│   └── ...
├── Source/               # 所有 C++ 代码
│   └── MyUnrealProject/
│       ├── MyUnrealProject.Build.cs
│       ├── MyUnrealProject.h
│       ├── MyUnrealProject.cpp
│       ├── Characters/
│       ├── Weapons/
│       ├── Game/
│       ├── UI/
│       └── ...
├── Plugins/              # 插件模块
├── Intermediate/         # 临时构建文件（不手动编辑）
├── Binaries/             # 编译生成的可执行文件
├── Saved/                # 日志、自动保存等
├── .uproject             # 项目描述文件
└── .gitignore
```

---

## UE 项目设计理念：

| 特征                   | 类似我们自建项目的目录                        |
| -------------------- | ---------------------------------- |
| `Source/` 里按功能模块分类   | 对应 `src/game/...`、`src/engine/...` |
| `Content/` 放资源       | 对应 `assets/` 或 `res/`              |
| `Config/` 放默认配置（INI） | 对应 `assets/config/` 或 `config/`    |
| `Plugins/` 用于模块插件化扩展 | 对应 `plugins/`                      |

---

## 🔄 UE 风格与 CMake 项目的兼容思路：

如果你要做一个 **C++ 游戏引擎项目，模仿 UE 项目结构但不使用 UE 本身**：

* 完全可以按 `Source/ + Content/` 风格分离代码和资源
* CMake 构建逻辑用 `add_subdirectory()` 模拟模块化（如插件、UI、物理等模块）
* `Content/` 可作为 `assets/` 的别名
* `.uproject` 相当于 `CMakeLists.txt` + `project.json`

| ------------------------------ | ---------------------------------- |
| `Source/MyProject/Characters/` | `src/game/characters/`             |
| `Source/MyProject/GameMode/`   | `src/game/gamecore/`               |
| `Content/Levels/`              | `assets/levels/`                   |
| `Config/DefaultGame.ini`       | `assets/config/game.json` 或 `.ini` |
